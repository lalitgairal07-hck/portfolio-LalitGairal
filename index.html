About Me

Tic-Tac-Toe

The Tic-Tac-Toe game is a Python-based project that allows two players to play the classic 3×3 grid game. It is built using basic programming concepts such as functions, loops, conditionals, and lists. The program checks for valid moves, updates the board after each turn, and determines whether a player has won or if the game ends in a draw. This project demonstrates fundamental problem-solving skills and provides a solid understanding of how game logic works in Python.

Weather App

The Weather App is a web-based application that allows users to check real-time weather conditions for any city. It uses HTML, CSS, and JavaScript on the frontend to provide a clean and interactive interface, while MySQL is used on the backend to store search history or user data. The app fetches live weather information from an external API and displays details such as temperature, humidity, and weather conditions in an easy-to-understand format.
